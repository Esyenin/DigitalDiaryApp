# Краткое описание изменений

## Тесты схем

- Расширен большой словарь тестовых данных в `tests/test_schemas.py`.
- Для всех основных моделей добавлены `valid` и `invalid` payload-ы по операциям `create`, `filter`, `update`, `delete`.
- Кейсы добавлены в двух вариантах: обычные словари и ORM-объекты моделей.
- Проверяются типы данных, обязательные поля, `None`, пустые строки, строки из пробелов, максимальные длины строк и комбинированные ошибки.
- Длины строк берутся из `MAX_LEN`, а не захардкожены в тестах.

## Лимиты строк в моделях

- В модели `Student`, `Schedule`, `Lesson`, `Comment` добавлены словари `MAX_LEN`.
- Поля `String(...)` теперь используют эти лимиты из моделей.
- Это нужно, чтобы схемы и тесты брали ограничения из одного источника.

## Общий ORM-сервис

- Добавлен новый сервис `OrmService` в `app/services/ormservice.py`.
- Он хранит SQLAlchemy-сессию и распределяет операции по конкретным сервисам моделей.
- Сервис умеет создавать, читать, обновлять и удалять записи через методы `create`, `create_many`, `get_many`, `get_one`, `update`, `update_one`, `delete`.
- Поддерживается поиск конкретного сервиса по имени сущности, ORM-классу, ORM-объекту или экземпляру сервиса.
- Добавлены методы управления сессией: `commit`, `rollback`, `close`, а также поддержка контекстного менеджера.

## Логирование

- В `BaseService` добавлено логирование ошибок валидации.
- В `OrmService` добавлено логирование успешных операций, отклоненных payload-ов и ошибок при работе с БД.

## Тесты сервисов

- Добавлены тесты для `OrmService`: проверка маршрутизации, CRUD-сценария и логирования ошибок.
- Исправлены хрупкие места в существующих DB/service-тестах, чтобы они не зависели от старых записей в локальной PostgreSQL.
