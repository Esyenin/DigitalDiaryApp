# Архитектура

Backend приложения представлен тремя основными слоями:

1. SQLAlchemy-модели предметной области.
2. Pydantic-схемы валидации и передачи данных.
3. Сервисы сущностей и фасад `OrmService`.

Архитектурный раздел последовательно описывает ответственность слоёв,
их зависимости, контракты операций и предусмотренные точки расширения.
