# Состояние проекта

Страница объединяет зафиксированный baseline и автоматически вычисляемое
состояние основных компонентов проекта.

Автоматическая сводка пересчитывается при каждой Sphinx-сборке. Если после
принятой базовой точки обнаружены изменения кода, оценка соответствующих
компонентов автоматически становится более осторожной, пока состояние не
будет подтверждено вручную.

Известные ошибки полного набора тестов относятся к подсистеме
`app/io_tools`, не включённой в подробный охват текущего архитектурного
аудита.

:::{admonition} Интерпретация автоматической оценки
:class: note

`TESTED` в сохранённом baseline означает подтверждённое состояние на момент
принятой базовой точки. Если соответствующий код изменяется после неё,
автоматическая оценка проверки сбрасывается до `UNVERIFIED`.

`PRODUCT VERIFIED` назначается только вручную после проверки сценария в
работающем приложении.
