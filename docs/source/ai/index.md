# Для ИИ

Раздел предназначен для предоставления структурированного контекста
инструментам автоматизированной разработки.

В состав раздела входят:

- краткий контекст проекта;
- полный архитектурный контекст;
- глоссарий предметной области;
- архитектурные инварианты;
- карта файлов и компонентов;
- команды проверки;
- правила безопасного изменения исходного кода.
