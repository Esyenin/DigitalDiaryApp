# О проекте

Раздел содержит сведения о назначении DigitalDiaryApp, категориях
пользователей, функциональных возможностях и границах текущей версии.

## Текущий охват

В текущей версии документации подробно рассматриваются:

- `app/models`;
- `app/schemas`;
- `app/services`.

Сведения об остальных подсистемах включаются после проведения отдельного
аудита исходного кода.
