# О проекте

DigitalDiaryApp — **Электронный журнал**, предназначенный для организации
и учёта учебной деятельности преподавателя.

Приложение служит персональным рабочим инструментом для ведения учебных
групп, расписания, занятий, посещаемости, результатов обучения и
отчётности.

:::{admonition} Разделение концепции и реализации
:class: note

Описание продукта определяет целевое назначение системы.

Фактическая готовность функций приводится в разделе
[«Состояние проекта»](../status/index.md). Перспективные требования не
представляются как возможности текущей версии.
:::

## Пользователь

Непосредственным пользователем приложения является преподаватель.

Студенты, кураторы, сотрудники кафедры и иные лица не работают с
приложением напрямую. Подготовленные отчёты могут передаваться им вне
Электронного журнала.

## Основные принципы

Продукт проектируется с учётом следующих принципов:

- локальная работа без обязательного подключения к интернету;
- отсутствие обязательной авторизации;
- хранение данных за несколько учебных лет;
- выбор одного активного учебного года в интерфейсе;
- загрузка данных из хранилища по мере необходимости;
- поддержка нескольких дисциплин и учебных групп;
- формирование семестровых и годовых отчётов;
- возможность переноса данных между устройствами;
- минимизация количества действий при проведении занятия.
