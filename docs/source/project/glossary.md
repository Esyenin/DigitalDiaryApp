# Глоссарий

```{glossary}
Электронный журнал
    Персональное приложение преподавателя для ведения данных об учебной
    деятельности, посещаемости, результатах и отчётности.

Учебный год
    Область организации и архивирования учебных данных. В интерфейсе
    одновременно выбирается один активный учебный год.

Активный учебный год
    Выбранный пользователем рабочий контекст, определяющий отображаемые
    семестры, дисциплины, группы, занятия и результаты.

Архивный учебный год
    Учебный год, данные которого сохранены в хранилище, но не являются
    текущим рабочим контекстом.

Семестр
    Основной учебный период, входящий в учебный год.

Дисциплина
    Самостоятельное направление преподавательской работы в пределах
    учебного периода. Одна дисциплина может быть связана с несколькими
    учебными группами.

Учебная группа
    Организованный список студентов, участвующих в учебном процессе.

Студент
    Участник учебной группы, сведения о котором и результаты которого
    фиксируются преподавателем.

Расписание
    Набор повторяющихся параметров проведения занятий, включая день,
    время, вид занятия и связанные группы.

Занятие
    Конкретное проведение дисциплины в установленную дату.

Посещаемость
    Сведения о присутствии или отсутствии студента на конкретном занятии.

Опоздание
    Интервал между завершением переклички и последующей отметкой
    присутствия прибывшего студента.

Результат обучения
    Зафиксированный итог учебной деятельности студента: балл, оценка,
    зачёт, отметка о выполнении или иной показатель.

Модель оценивания
    Набор правил, определяющих шкалу, диапазон, стоимость работ,
    суммирование и порядок вычисления результатов.

Правила дисциплины
    Модель оценивания, применяемая по умолчанию ко всем занятиям
    дисциплины, если занятие не содержит собственных переопределений.

Правила занятия
    Переопределение модели оценивания для конкретного занятия.

Модуль
    Часть семестра, объединяющая занятия и результаты для промежуточного
    подведения итогов.

Учебное событие
    Зафиксированное действие или обстоятельство учебного процесса,
    например занятие, консультация, опоздание или дисциплинарное событие.

Консультация
    Учебное событие, которое может проводиться без привязки к одной
    учебной группе и включать студентов из разных групп.

Индивидуальный план
    Набор этапов, задач и комментариев по курсовой, выпускной,
    проектной или иной индивидуальной работе студента.

Карточка реквизитов
    Независимый шаблон сведений преподавателя и организации,
    используемый исключительно при формировании отчётов.

Отчёт
    Документ, сформированный на основании данных журнала, выбранного
    периода, параметров выборки и карточки реквизитов.

Импорт
    Загрузка данных в приложение из внешнего файла.

Экспорт
    Выгрузка данных приложения во внешний файл для переноса, резервного
    копирования, отчётности или дальнейшей обработки.

Синхронизация
    Согласование изменений между несколькими устройствами или копиями
    данных.

Рабочий контекст
    Совокупность выбранных пользователем учебного года, семестра,
    дисциплины, группы и других параметров, ограничивающих отображаемые
    данные.
```
