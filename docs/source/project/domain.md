# Предметная область

## Общая структура

Основные данные Электронного журнала организуются вокруг учебного года.

```text
Учебный год
├── Семестры
├── Дисциплины
├── Учебные группы
└── Отчёты

Дисциплина
├── Учебные группы
├── Расписание
├── Занятия
├── Модули
└── Правила оценивания
```

Карточки реквизитов в эту структуру не входят. Они хранятся отдельно и
используются только при формировании отчётных документов.

## Учебный год

Учебный год является областью организации и архивирования данных.

В интерфейсе одновременно выбирается один активный учебный год.
Предыдущие годы сохраняются в хранилище и становятся доступны после
переключения рабочего контекста.

Учебный год может включать несколько семестров.

## Семестр

Семестр является основным учебным периодом.

В пределах семестра могут определяться:

- даты начала и окончания;
- учебные недели;
- праздничные и неучебные дни;
- модули;
- расписание;
- занятия;
- правила начисления результатов.

Отчётность может формироваться как за отдельный семестр, так и за учебный
год в целом.

## Дисциплина

Дисциплина представляет самостоятельное направление преподавательской
работы в пределах учебного периода.

К одной дисциплине может быть привязано несколько учебных групп.
Одна учебная группа также может участвовать в нескольких дисциплинах.

Дисциплина определяет:

- наименование;
- учебный период;
- связанные группы;
- расписание;
- занятия;
- модули;
- правила оценивания по умолчанию;
- параметры формирования отчётов.

## Учебная группа

Учебная группа объединяет студентов, участвующих в учебном процессе.

Группа может быть связана с несколькими дисциплинами. При этом сведения
о посещаемости, занятиях и результатах фиксируются в контексте конкретной
дисциплины и учебного периода.

## Студент

Студент относится к учебной группе.

Для различения однофамильцев могут использоваться:

- полное имя;
- номер группы;
- идентификатор или номер зачётной книжки;
- корпоративная электронная почта.

Студент не является пользователем приложения. Все сведения о его учебной
деятельности вносит преподаватель.

## Расписание

Расписание определяет повторяющиеся параметры проведения занятий.

Запись расписания может включать:

- день недели;
- время;
- вид занятия;
- чётность недели;
- связанные учебные группы;
- признак оценочного занятия.

Расписание используется как основание для создания конкретных занятий.

## Занятие

Занятие представляет конкретное проведение дисциплины в определённую дату.

Для занятия могут фиксироваться:

- дата;
- тема;
- связанные группы;
- присутствующие студенты;
- результаты;
- комментарии;
- опоздания;
- события и нарушения;
- применённые правила оценивания.

Одно занятие может проводиться одновременно для нескольких учебных групп,
связанных с дисциплиной.

## Посещаемость и опоздание

Посещаемость отражает присутствие или отсутствие студента на конкретном
занятии.

Перспективная модель должна различать как минимум:

- присутствие;
- отсутствие без подтверждённой причины;
- отсутствие по подтверждённой причине;
- опоздание.

После завершения переклички время опоздания может рассчитываться
автоматически по часам устройства.

## Результат обучения

Результат обучения представляет зафиксированный итог учебной деятельности
студента.

В зависимости от применённой модели оценивания результатом может быть:

- числовой балл;
- традиционная оценка;
- результат «зачтено» или «не зачтено»;
- отметка о выполнении;
- результат отдельной попытки;
- набор выполненных критериев.

## Модель оценивания

Правила оценивания определяются на двух уровнях.

### Уровень дисциплины

Дисциплина задаёт значения по умолчанию:

- тип шкалы;
- допустимый диапазон;
- виды работ;
- стоимость работ;
- правила суммирования;
- модули;
- пороги итоговых результатов.

### Уровень занятия

Конкретное занятие может использовать правила дисциплины либо
переопределять их.

Переопределение может включать:

- другую шкалу;
- собственный диапазон баллов;
- отдельную стоимость работы;
- результат «зачтено» или «не зачтено»;
- чек-лист критериев;
- индивидуальные правила начисления.

Приоритет настроек:

```text
Настройки занятия
        ↓
Настройки дисциплины
        ↓
Системные значения по умолчанию
```

Уже зафиксированный результат должен сохранять сведения о применённой
модели оценивания. Изменение настроек не должно автоматически изменять
исторические результаты.

## Модуль

Модуль является частью семестра и объединяет занятия и результаты,
участвующие в промежуточном подведении итогов.

Для модуля могут определяться:

- период действия;
- виды учитываемых работ;
- правила суммирования;
- максимальное количество баллов;
- пороги результатов.

## Карточки реквизитов

Карточки реквизитов находятся вне предметной модели Электронного журнала.

Они:

- не принадлежат учебному году;
- не связываются с дисциплинами;
- не используются при учёте занятий;
- не влияют на оценки и посещаемость;
- выбираются только при формировании отчётного документа;
- могут применяться повторно для разных лет, дисциплин и получателей.

Карточки реквизитов относятся к настройкам отчётности, а не к ведению
учебного журнала.
