# API-справочник

Раздел содержит автоматически сформированную документацию публичных
компонентов backend.

Исходными данными служат сигнатуры, аннотации типов и docstring,
расположенные непосредственно в Python-модулях проекта.

:::{admonition} Текущий охват
:class: note

В справочник включены:

- ORM-модели из `app.models`;
- Pydantic-схемы из `app.schemas`;
- сервисы сущностей и `OrmService` из `app.services`.

Содержание страниц отражает текущее состояние исходного кода и на следующем
этапе будет проверено на полноту и точность.
:::
