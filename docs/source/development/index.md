# Разработка

Раздел объединяет сведения, необходимые для локальной разработки, проверки
и сопровождения DigitalDiaryApp.

Он предназначен для разработчиков, которые запускают приложение, изменяют
исходный код, выполняют проверки или сопровождают документацию проекта.

## Основные направления

:gutter: 3

Настройка Python-окружения и зависимостей проекта.

**Документация будет добавлена после проверки фактического процесса настройки.**

:::{grid-item-card} Запуск приложения

Локальный запуск приложения, рабочее окружение и связанные ресурсы.

**Документация будет добавлена после проверки фактической точки запуска.**
:::

:::{grid-item-card} Тестирование

Запуск целевых и полных наборов тестов, интерпретация результатов и

## Что использовать сейчас

На текущем этапе полностью определён процесс ведения документации.

Для изменений документации и связанных изменений кода используется подраздел
[«Ведение документации»](documentation/index.md).

Текущее подтверждённое состояние основных компонентов доступно в разделе
[«Состояние»](../status/index.md).

Инструкции по окружению, запуску и тестированию будут добавляться только после
проверки фактических команд и точек входа проекта. До этого раздел не должен
содержать предположительные команды.
