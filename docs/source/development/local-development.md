# Локальная разработка

Страница содержит минимальный рабочий процесс для запуска проекта и проверки изменений.

## Подготовка окружения

Создать виртуальное окружение:

```powershell
python -m venv .venv
```

Установить зависимости:

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Для дальнейших команд можно использовать Python виртуального окружения напрямую,
без обязательной активации `.venv`.

## База данных

Настройки подключения определяются в `config.py`.

Если полностью заданы параметры PostgreSQL:

```text
DB_USER
DB_PASSWORD
DB_HOST
DB_PORT
DB_NAME
```

используется PostgreSQL.

Если конфигурация PostgreSQL отсутствует или заполнена не полностью, приложение
использует локальную SQLite-базу. По умолчанию это `digital_diary.db`.

Файл `.env` в корне проекта можно использовать для локальных параметров
подключения, но для запуска через SQLite он не обязателен.

## Запуск приложения

Из корня репозитория:

```powershell
& .\.venv\Scripts\python.exe main.py
```

Корневая точка входа — `main.py`.

## Запуск тестов

Полный набор тестов:

```powershell
& .\.venv\Scripts\python.exe -m pytest tests
```

Текущее подтверждённое состояние тестов и известные проблемы фиксируются в
разделе «Состояние», а не на этой странице.

## Сброс базы данных

В корне проекта есть служебный скрипт `clear_database.py`.

:::{admonition} Удаление данных
:class: warning

`clear_database.py` удаляет все таблицы выбранной базы данных и создаёт их заново.
Он не является обычным шагом запуска или разработки.
:::
