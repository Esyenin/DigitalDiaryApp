# DigitalDiaryApp

**Электронный журнал преподавателя**

DigitalDiaryApp предназначен для локального ведения учебных групп,
расписания, занятий, посещаемости, результатов обучения и отчётности.

:::{admonition} Статус документации
:class: note

Документация является архитектурным снимком проекта.

- Ветка документации: `docs/project-baseline`
- Baseline исходного кода: `c31d21ed28219fbcbc07a63861f727571ecd0047`
- Python: `3.14.0`
- Backend-тесты: `1438 passed`
- Pylint для `models`, `schemas`, `services`: `9.94/10`
:::

## Поиск по пользовательским и техническим терминам

При поиске можно использовать как предметные, так и программные названия.

| Предметный термин | Техническое имя |
|---|---|
| учебная группа | `Group` |
| студент | `Student` |
| расписание | `Schedule` |
| занятие, пара | `Lesson` |
| посещаемость, присутствие | `Attendance` |
| оценка, балл, результат | `Mark` |
| комментарий, замечание | `Comment` |
| сервис хранения, ORM-фасад | `OrmService` |

## Принцип организации

Каждый вид информации имеет основной раздел:

- требования к продукту находятся в разделе «О проекте»;
- фактическое устройство кода — в разделе «Архитектура»;
- точные сигнатуры — в разделе «API»;
- команды и процессы — в разделе «Разработка»;
- результаты проверок — в разделе «Состояние»;
- сжатый машинный контекст — в разделе «Для ИИ».

Внутренние страницы подключаются к навигации соответствующего раздела
через его дерево документов. Новую крупную тему рекомендуется оформлять
как каталог с собственным `index.md`.
